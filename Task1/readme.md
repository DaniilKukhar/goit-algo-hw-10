# Порівняння жадібного алгоритму та динамічного програмування

## Жадібний алгоритм

Жадібний алгоритм працює дуже швидко, оскільки на кожному кроці вибирає найбільший можливий номінал монети.

### Складність:
O(n), де n — кількість номіналів монет.

### Переваги:
- Простота реалізації
- Висока швидкість роботи
- Ефективний для великих сум

### Недоліки:
- Не завжди знаходить мінімальну кількість монет для довільних наборів монет


---

## Динамічне програмування

Алгоритм динамічного програмування перебирає всі можливі варіанти формування суми та знаходить оптимальний результат.

### Складність:
O(amount * n)

де:
- amount — сума
- n — кількість номіналів монет

### Переваги:
- Завжди знаходить мінімальну кількість монет
- Підходить для будь-яких наборів номіналів

### Недоліки:
- Працює повільніше при великих сумах
- Використовує більше пам’яті


---

# Висновок

Для набору монет [50, 25, 10, 5, 2, 1] жадібний алгоритм є більш ефективним, оскільки він швидше працює та також знаходить оптимальний результат.

Алгоритм динамічного програмування є універсальнішим, але при великих сумах працює повільніше через необхідність перебору великої кількості варіантів.

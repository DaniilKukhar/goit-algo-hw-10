# Метод Монте-Карло для обчислення інтеграла

## Опис

У роботі було реалізовано метод Монте-Карло для обчислення визначеного інтеграла функції:

f(x) = x²

на проміжку від 0 до 2.

---

# Суть методу Монте-Карло

Метод Монте-Карло використовує випадкові точки для наближеного знаходження площі під графіком функції.

Було побудовано прямокутник:
- ширина: (b - a)
- висота: max(f(x))

Після цього випадковим чином генерувалися точки всередині прямокутника.

Якщо точка потрапляла під графік функції, вона враховувалась.

Формула оцінки інтеграла:

Integral ≈ (кількість точок під графіком / загальна кількість точок) × площа прямокутника

---

# Результати

## Метод Монте-Карло

Приблизний результат:
2.66

## Результат scipy.quad

2.666666666666667

## Аналітичний результат

∫ x² dx від 0 до 2:

= x³ / 3 | 0..2
= 8 / 3
= 2.6666666666666665

---

# Висновок

Метод Монте-Карло дав результат, близький до точного значення інтеграла.

Невелика похибка виникає через випадковий характер генерації точок.

Чим більше випадкових точок використовується, тим точнішим стає результат.
